# 教材 JSON 格式與 5 句例句校驗技能

本技能用於固化「多益網頁遊戲專案」的單字教材格式，保證日後教材擴充（例如新增 Unit 22 及以後的單元）時，不會再發生格式不一或例句不足的問題。

---

## 🛠️ 核心自動化工具
本技能配套提供了一個位於 `.agents/skills/vocab-validator/scripts/check_and_format.py` 的 Python 腳本。

### 該腳本執行的工作包括：
1. **補全與核對 ID**：確保每個單字物件都有正確遞增的 `"id"`。
2. **檢測詞性標記**：檢查是否有漏掉 `"part_of_speech"` 屬性。
3. **驗證中文釋義**：檢查是否包含有效中文釋義。
4. **校驗 5 句例句數量**：
   - 檢查 `examples` 陣列是否剛好有 5 個物件。
   - 檢查每句例句是否正確包含英文原句 (`en`) 與繁體中文翻譯 (`zh`)。
5. **JSON 屬性重組標準化**：
   - 將單字物件的所有鍵排序固化為：`"id"`, `"word"`, `"part_of_speech"`, `"meaning"`, `"examples"`。
   - 將格式化後的資料以 UTF-8 編碼（`ensure_ascii=False`）漂亮排版寫回原 JSON 檔案。

---

## 📖 執行規範與工作流程

當未來需要擴充教材或檢查現有教材時，AI 助理應遵循以下流程：

### 步驟 1：執行本地格式檢測
使用終端機指令對目標教材 JSON 檔案執行檢測（將 `<path-to-json>` 替換為實際教材路徑，如 `data/books/high_school_L3_22.json`）：
```powershell
python .agents/skills/vocab-validator/scripts/check_and_format.py <path-to-json>
```

### 步驟 2：根據檢測結果補全資料
* **如果提示詞性缺失**：自動調用模型判定詞性，寫入 `"part_of_speech"` 欄位。
* **如果提示例句不足 5 句**：
  1. 對於例句不足的單字，呼叫大型語言模型（LLM）為其生成補足至 **5 個** 符合高中英語 Level 3 教材程度的英文例句，且例句中必須使用到該單字或其變體。
  2. 同步為每句例句生成準確、道地的繁體中文翻譯。
  3. 將生成好的數據加入對應單字的 `examples` 陣列中。

### 步驟 3：重新執行檢測與標準化
資料補全後，重新執行步驟 1 的檢測腳本，直到腳本輸出：
`[+] 檢測完成！所有單字格式合規，詞性完整，例句均足額 5 句！`
並確認以 UTF-8 正確覆寫寫回。

## ⚠️ 注意事項
* 備份唯讀性：在對 JSON 檔案進行任何寫入操作前，務必將其複製一份備份至 `bak/` 目錄中，檔名附帶時間戳。
* 前端 Cache-Busting：JSON 更新後，前端 `fetch` 應繼續使用帶有隨機時間戳 `?t=Date.now()` 的請求，以徹底清洗快取。
